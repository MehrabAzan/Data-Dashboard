# Web Development Project 5 - *Rick and Morty Character Dashboard*

Submitted by: **Mehrab Azan**

This web app: **displays Rick and Morty character data in a searchable and filterable dashboard.**

Time spent: **10** hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] **The app displays a list of data fetched using an API call**
- [x] **App dashboard includes at least three summary statistics about the data, such as**
  - [x] 20 characters loaded
  - [x] alive characters count
  - [x] average episode appearances
- [x] **A search bar allows the user to search for an item in the fetched data**
- [x] **An additional filter allows the user to filter items in the fetched data by another attribute**
- [x] **The user can use multiple filters at once**

The following **optional** features are implemented:

- [x] Multiple filters can be applied simultaneously
- [x] Filters use different input types such as a text input and a slider
  - e.g., as a text input, a dropdown or radio selection, and/or a slider
- [x] The user can enter specific bounds for filter values

The following **additional** features are implemented:

- [x] Character rows include images plus origin and location details
- [x] The dashboard includes loading, error, and empty-state feedback
